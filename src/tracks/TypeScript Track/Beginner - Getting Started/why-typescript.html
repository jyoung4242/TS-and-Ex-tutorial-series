What Is TypeScript?

TypeScript is JavaScript with a superpower: types. It's a language developed by Microsoft that compiles down to plain JavaScript, meaning anything TypeScript can do, it ultimately becomes JavaScript that any browser or Node.js environment can run.

But before it becomes JavaScript, TypeScript checks your code for mistakes. It reads your code, understands what types of values you're working with, and tells you when something doesn't add up before you even run the program.

The Problem TypeScript Solves

Consider this JavaScript function:


// JavaScript
function addPoints(player, amount) {
  player.score = player.score + amount;
  return player;
}

This looks fine. But what happens when someone calls it like this?


// Oops — "10" is a string, not a number
addPoints(player, "10");

// Result: player.score = 0 + "10" = "010"  😱

JavaScript won't warn you. The code runs. You get a bug that's hard to track down. In a game, this could mean a player's score shows as "010" instead of 10.

Now here's the same function in TypeScript:


// TypeScript
function addPoints(player: Player, amount: number): Player {
  player.score = player.score + amount;
  return player;
}

If you try to call addPoints(player, "10"), TypeScript immediately tells you:


Error: Argument of type 'string' is not assignable to parameter of type 'number'.

Bug caught. Before you even run the code.

What is "type safety"?

Type safety means your tools can verify that the types of values in your program are used correctly. A type error is when you use a value in a way that doesn't match its type — like adding a string where a number is expected.

Why TypeScript for Game Development?

Games are complex. You'll have:

  • Players, enemies, items, projectiles, levels…
  • Game state that changes every frame
  • Events, inputs, collision detection, scoring…

Without types, it's easy to lose track of what each variable holds. With TypeScript, your editor knows the shape of your data and can autocomplete, catch errors, and guide you as you write.

Also, browser based games run on all platforms that support JavaScript. Since TypeScript compiles to JavaScript, you get the same wide compatibility with the added benefits of type safety and better tooling. All platforms inlcude mobile, PC, and apple devices.

ExcaliburJS is written in TypeScript

TypeScript's Other Benefits

  • Autocomplete — your editor can suggest methods and properties
  • Documentation — types describe intent, making code self-documenting
  • Confidence — fewer runtime surprises
⚠
TypeScript isn't magic

TypeScript can only catch type errors. It won't prevent logic errors ("the enemy should move left, not right") or runtime errors from external systems. It's a powerful tool, not a guarantee.

Summary
  • TypeScript is JavaScript plus static type checking
  • It catches type errors before you run your code
  • Type safety prevents entire categories of common bugs
  • ExcaliburJS is TypeScript-native, giving you great editor support
  • TypeScript compiles to plain JavaScript — it runs everywhere JS runs
