Welcome to TypeScript Academy

You're about to learn TypeScript, one of the most in-demand programming languages in the world, through one of the most enjoyable lenses imaginable: game development.

Every concept you learn here will be applied in the context of building games with ExcaliburJS, a TypeScript-first 2D game engine. You'll never wonder "when would I use this?", you'll be using it to make something fun.

ℹ
Note

The intended audience for this course is Javascript developers who want to learn TypeScript, and game developers who want to learn how to use TypeScript in their projects. If You don't need any prior TypeScript or game development experience. Basic familiarity with JavaScript is helpful as the lessons will assume you understand fundamental programming concepts like variables, functions, and loops. But if you're new to programming entirely, you'll still be able to follow along — just take your time and refer to the resources in the sidebar as needed.

How This Course Works

The curriculum is organized into three tracks:

  • TypeScript Track — Learn the language itself. Types, functions, classes, interfaces, generics, and more. This is the foundation.
  • Excalibur Track — Apply your TypeScript skills to build real games. Actors, scenes, physics, input, audio, and more.
  • Projects Track — Put it all together. Build complete games from scratch.
📌
The Golden Rule

Each lesson teaches one thing. TypeScript lessons focus on TypeScript. Excalibur lessons focus on Excalibur. We never mix the two in the same lesson.

Lesson Structure

Every lesson follows the same structure so you always know what to expect:

  1. Learning Objectives — what you'll be able to do
  2. Content — explanation + code examples
  3. Playground — try it live in ExcaliburJS
  4. Exercise — guided practice
  5. Summary — key takeaways

Tracking Your Progress

Use the Mark Complete button at the top of each lesson when you're done. Your progress is saved locally — no account required. The sidebar shows your completion status with ✓ and ○ indicators.

💡
Tip

Don't rush. Read the lesson, run the examples, complete the exercises. Understanding each concept deeply is more valuable than moving fast.
