The Building Blocks of Types

Every value in TypeScript has a type. The most fundamental types are called primitives — they represent single, indivisible values. TypeScript has three core primitives:

  • string — text values like "Hello" or "Player One"
  • number — numeric values like 42, 3.14, or -5
  • boolean — logical values: either true or false

Annotating Primitive Types

You annotate a variable's type by placing a colon and the type name after the variable name: 


// Strings — for text
const playerName: string = "Aria";
const levelName: string = "The Dark Forest";
let statusMessage: string = "Ready";

// Numbers — for any numeric value (no int/float distinction)
const maxHealth: number = 100;
const speed: number = 2.5;
let score: number = 0;

// Booleans — for true/false flags
const isAlive: boolean = true;
let hasKey: boolean = false;
const gameOver: boolean = false;
ℹ
TypeScript has one number type

Unlike some languages that separate integers from floats (e.g., int and float in C), TypeScript uses a single number type for all numeric values. 42 and 3.14 are both number.

What Happens With the Wrong Type?

If you try to assign a value that doesn't match the declared type, TypeScript reports an error: 


let score: number = 0;

score = 100;        // ✅ Fine — 100 is a number
score = "victory";  // ❌ Error: Type 'string' is not assignable to type 'number'
score = true;       // ❌ Error: Type 'boolean' is not assignable to type 'number'

The error appears in your editor immediately — you don't have to run the code to find out.

💡
Think of types as promises

When you declare let score: number, you're making a promise: "this variable will always hold a number." TypeScript holds you to that promise everywhere score is used.

Game Example

Here's how primitives look in a game context:


// Player state — all three primitives in use
const playerName: string  = "Hero";
let   health:     number  = 100;
let   mana:       number  = 50;
let   isAlive:    boolean = true;
let   hasShield:  boolean = false;

// When the player takes damage
function takeDamage(amount: number): void {
  health = health - amount;
  if (health <= 0) {
    health = 0;
    isAlive = false;
  }
}

takeDamage(30);  // health = 70, isAlive = true
takeDamage(80);  // health = 0, isAlive = false

Summary
  • The three core primitives are string, number, and boolean
  • Type annotations use a colon: let score: number = 0
  • TypeScript reports an error if you assign the wrong type
  • TypeScript's number handles both integers and decimals
  • Types are a promise about what kind of value a variable will hold
