The Anatomy of an Excalibur Game

Every ExcaliburJS game needs three things to run:

  1. An Engine — the game loop, canvas, and configuration
  2. A Scene — a container for your game objects (one is created by default)
  3. A call to game.start() — kicks off the loop

Here is the minimal working game:


import * as ex from "excalibur";

// Create the engine — this creates the canvas
const game = new ex.Engine({
  width: 800,
  height: 600,
  backgroundColor: ex.Color.Black,
});

// Start the game
game.start();

That's it. Run this and you get a black canvas with a running game loop. Not exciting yet — but the engine is alive.

Adding an Actor

An Actor is any object in your game world — a player, enemy, platform, bullet, or collectible. Actors have a position, size, and color. 


import * as ex from "excalibur";

const game = new ex.Engine({
  width: 800,
  height: 600,
  backgroundColor: ex.Color.Black,
});

// Create a simple blue square actor
const player = new ex.Actor({
  x: 400,
  y: 300,
  width: 40,
  height: 40,
  color: ex.Color.Blue,
});

// Add the actor to the default scene
game.add(player);

// Start!
game.start();

Now you have a blue square centered on the screen. The game loop is running — Excalibur is calling update() and draw() 60 times per second.

ℹ
The Game Loop

Every game runs a loop: update → draw → update → draw… forever. On each update, you move things. On each draw, Excalibur renders them. Excalibur manages this loop — you just write what should happen.

Understanding the Engine Config


const game = new ex.Engine({
  width: 800,          // Canvas width in pixels
  height: 600,         // Canvas height in pixels
  backgroundColor: ex.Color.Black,   // Background color
  displayMode: ex.DisplayMode.FitScreen,  // How to handle window resizing
});
💡
TypeScript at work

Notice how the Engine constructor accepts an object with specific properties. That object has a TypeScript type behind it — if you try to pass an unknown property, TypeScript will warn you. This is type safety helping you use the library correctly.

Summary
  • Every Excalibur game starts with new ex.Engine() and game.start()
  • Actors are game objects with position, size, and color
  • Use game.add(actor) to put an actor in the default scene
  • The game loop runs update → draw at 60fps automatically
  • TypeScript's type system helps you use the Excalibur API correctly
